# Task Gacha

**Gamified task management for brains that work differently.**

Turn your to-do list into a dopamine-fueled adventure. Task Gacha uses randomness and the thrill of the unknown to make productivity feel *exciting* instead of exhausting.

---

## What is Task Gacha?

Stuck between a million tasks? Can't decide what to do? **Let the gacha machine decide for you.**

Pull a random task, and get a burst of dopamine from the surprise. Skip it if you're not feeling it. Pull another. Keep going until you find something that clicks. Then set a timer and crush it.

It's simple. It's fun. And it actually works—especially if your brain runs on randomness and novelty.

---

## Why This Works (The Science Bit)

### For ADHD Brains
People with ADHD often struggle with task initiation and decision paralysis. Too many options = analysis paralysis. **Randomness solves this.** By removing the choice, you remove the friction.

### The Dopamine Hit
The unpredictability of not knowing which task you'll get creates a small dopamine spike. That same mechanism that makes gacha games addictive? We're channeling it toward *productivity* instead of spending money.

### Low Friction, High Motivation
- No more staring at your list thinking "ugh, where do I start?"
- No more decision fatigue
- Just pull, react, and go

## Features

- **Smart Gacha Draw** - Pulls from your task list based on time availability & task categories
- **Time Filters** - Set your available time, and only get tasks you can actually complete
- **Category Tags** - Organize tasks: Work, Chores, Health, Creative
- **Task Priority** - Set importance levels to weight the randomness
- **Timer** - Built-in Pomodoro-style timer for focused work
- **Skip Button** - Not feeling it? Pull another task instantly
- **No Pressure** - Close the overlay and go back to browsing—zero judgment
- **Simple & Calming** - Designed to reduce anxiety, not add to it

## Getting Started

### Installation

```bash
# Clone the repo
git clone https://github.com/yourusername/task-gacha.git
cd task-gacha

# Install dependencies
npm install

# Start the dev server
npm run dev
```

Then open `http://localhost:5173` in your browser and start pulling tasks!

### Building for Production

```bash
npm run build
```

The optimized build will be in the `dist/` folder.

## How to Use

1. **Add Tasks** - Go to the Inventory tab and add all your tasks with time estimates and categories
2. **Set Filters** - Choose your available time and preferred categories
3. **Pull a Task** - Click the gacha machine and watch what you get
4. **Decide** - Like it? Hit Start Timer. Not feeling it? Skip and pull again
5. **Focus** - Work on your task with the built-in timer
6. **Celebrate** - Hit Done and feel the win

---

## Pro Tips

- **Set realistic time limits** - If you say you have 20 mins, you'll only get 20-min tasks
- **Categorize thoughtfully** - Use filters to create "moods" (just want chores? Just pick chores!)
- **Don't overthink importance** - Rate tasks 1-3 based on what actually matters
- **Embrace the skip** - It's part of the magic. Sometimes you need to pull 3 times to find the right task—and that's ok
- **Use it for focus** - The timer + randomness combo is *chef's kiss* for ADHD brains
